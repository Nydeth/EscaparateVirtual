# 🛍️ EscaparateVirtual

> Plataforma web interactiva para la exhibición y gestión de catálogos de productos en línea.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-informational.svg)
![Stack](https://img.shields.io/badge/tech-HTML5%20%7C%20CSS3%20%7C%20JavaScript-blue)

## 📌 Descripción

**EscaparateVirtual** es una solución ligera pensada para negocios y comercios que desean exponer sus productos de forma clara, moderna y organizada. La plataforma permite a los usuarios explorar elementos de un catálogo, filtrar por categorías y consultar información detallada de cada artículo en tiempo real.

Diseñado con un enfoque centrado en la experiencia de usuario (UX) y optimizado para una navegación rápida en cualquier dispositivo.

---

## ✨ Características Principales

- 📦 **Catálogo Dinámico:** Renderizado de productos a partir de estructuras de datos flexibles (JSON/Objects).
- 🔍 **Filtrado y Búsqueda:** Búsqueda en tiempo real por palabras clave y categorización de productos.
- 📱 **Diseño Responsive:** Layout adaptativo (*Mobile-First*) optimizado para smarphones, tablets y PC.
- 🛒 **Vista de Detalle / Modal:** Inspección rápida de características, precios e imágenes detalladas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica del contenido.
- **CSS3:** Maquetación moderna utilizando CSS Grid y Flexbox, junto con transiciones fluidas.
- **JavaScript (ES6+):** Manipulación dinámica del DOM, gestión de eventos y filtrado de datos.
